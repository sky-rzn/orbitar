# ORBITAR — демо платформера в стиле 16-битных консолей

Sci-fi платформер на чистом HTML5 Canvas без зависимостей. Внутреннее разрешение
320×224 (как у SNES/Mega Drive) с целочисленным масштабированием, палитра из ~40 цветов,
все тайлы и спрайты генерируются кодом при загрузке — никаких внешних картинок.

Два сектора по 12 экранов, каждый со своим набором тайлов, фонов, врагов и боссом.

## Запуск

Открыть `index.html` в браузере (работает и с `file://`), либо:

```
python3 -m http.server 8000
# → http://localhost:8000
```

## Управление

| Клавиши                 | Действие                                   |
|-------------------------|--------------------------------------------|
| ← / → или A / D         | бег                                        |
| Z / Space / ↑ / W       | прыжок (чем дольше держать, тем выше)      |
| Z                       | переход в следующий сектор на экране CLEAR |
| R                       | рестарт сектора (на финале — всей миссии)  |
| C                       | вкл/выкл scanlines                         |
| набрать `LVL1` / `LVL2` | чит: в начало первого/второго сектора      |
| набрать `BOSS1`/`BOSS2` | чит: к боссу первого/второго сектора       |
| набрать `NEXT`          | чит: сразу в следующий сектор              |

## Сектор 7 — ORBITAL FOUNDRY

Холодная гамма: синий металл, циановый неон, маджента. 240×14 тайлов, 34 энергоячейки.

- **Платформы**: твёрдый грунт с автотайлингом, парящие антиграв-платформы, односторонние
  решётки, горизонтальная и вертикальная движущиеся платформы, пружина.
- **Опасности**: лазерные шипы, патрульные дроны (на них можно прыгнуть сверху), бездонные ямы.
- **Босс WARDEN** (3 деления): арена запирается энергобарьером. Босс парит и стреляет
  наводящимися снарядами, затем телеграфирует (жёлтые глаза) и бьёт об пол — от места удара
  расходятся ударные волны, которые надо перепрыгнуть. После удара люк на корпусе открыт:
  прыжок сверху на ядро снимает деление. Пока щит поднят (пунктирная рамка), касание смертельно.

## Сектор 12 — VERDANT REACTOR

Тот же язык («неон по тёмному металлу»), но гамма сдвинута: зелёный металл, фиолетовый
неон на кромках, лаймовая подсветка антиграва, янтарный расплав вместо бездонных ям,
бирюзовые споровые наросты. Фон — споровое небо с двойной луной, грибные башни реактора,
свисающие корни. 240×14 тайлов, 28 энергоячеек.

Новые механики:

- **Осыпающиеся плиты** — держат ~0.7 с под ногами (индикатор гаснет с циана в красный),
  затем рассыпаются и отрастают через 2.5 с.
- **Донные вентиляторы** — столб восходящего потока (до 8 тайлов), поднимает игрока
  к верхним маршрутам; внутри столба сохраняется полный контроль по горизонтали.
- **Лазерные затворы** — луч от излучателя вниз, цикл «выкл → жёлтое предупреждение → луч».
  Проходы открываются только в паузах.
- **Расплав** — озёра вместо ям: поверхность анимирована, касание смертельно.

Новые враги:

- **CRAWLER** — ползун, шагает по грунту, разворачивается у стен и обрывов, гибнет от прыжка сверху.
- **SENTRY** — стационарная турель: наводится на сторону игрока, 28 кадров телеграфа (жёлтый
  ствол), затем горизонтальный выстрел. Гибнет от прыжка сверху. При возрождении на чекпоинте
  таймеры турелей сбрасываются — игрок всегда получает полный телеграф.
- **WASP** — перекрашенный дрон-патрульный.

**Босс ROOTMIND** (4 деления) — корневая машина, дерётся по земле, а не в воздухе:

1. *Stalk* — идёт к игроку по полу и плюётся веером из трёх спор по навесной траектории.
2. *Tell* — дрожит, глаза желтеют: телеграф рывка (~0.9 с).
3. *Dash* — рывок через всю арену; надо перепрыгнуть или отсидеться на боковых решётках.
4. *Crash* — удар о стену раскрывает броню: ядро наверху уязвимо ~2.7 с, прыжок сверху снимает деление.
5. С третьего деления дополнительно капает расплавом с потолка и выпускает ползунов из углов.

Скорость, частота спор и длительность фаз растут с каждым попаданием.

## Общее

- **Сбор**: 62 энергоячейки на два сектора, порталы выхода, по двенадцать чекпоинтов на сектор.
- **Физика**: ускорение/трение, переменная высота прыжка, coyote time, jump buffer,
  перенос игрока движущейся платформой, сплющивание при приземлении, частицы.
- **Графика**: три слоя параллакса на сектор, анимированные тайлы, битмап-шрифт 3×5 для HUD.
- Побеждённый босс не воскресает при возрождении на чекпоинте.

## Файлы

- `index.html` — канвас и подсказка по управлению.
- `js/assets.js` — палитра, темы (таблицы подмены цветов), генератор спрайтов из пиксель-карт,
  процедурные тайлы и фоны для обоих секторов.
- `js/level.js` — карта сектора 7 и его метаданные.
- `js/level2.js` — карта сектора 12 и его метаданные.
- `js/game.js` — движок: ввод, коллизии, сущности, механики, камера, боссы, отрисовка, HUD.

Тема сектора задаётся одной таблицей подмены ключей палитры (`TH_REACTOR` в `assets.js`) —
все тайлы, декор, порталы и враги перекрашиваются из тех же пиксель-карт.

## Отладка

- `index.html#lv=2` — старт во втором секторе.
- `index.html#lv=2&x=43&y=10` — старт игрока в указанном тайле (удобно смотреть части уровня).
- `index.html#lv=2&x=221&y=10` — старт прямо у арены босса.
- `window.__dbg()` в консоли — текущее состояние уровня, игрока, врагов и босса.
- Чит-коды: `LVL1`/`LVL2` (начало сектора), `BOSS1`/`BOSS2` (чекпоинт у арены босса),
  `NEXT` (следующий сектор).

## Деплой

Продакшн: **https://orbitar.duckdns.org** — vps2, nginx, статика в `/var/www/orbitar`.

### Первичная настройка сервера

Один раз, от root:

```
scp deploy/provision.sh deploy/nginx-orbitar.conf root@vps2:/tmp/
ssh root@vps2 'CI_DEPLOY_PUBKEY="ssh-ed25519 AAAA... github-actions-deploy@orbitar" bash /tmp/provision.sh'
```

Скрипт заводит системного пользователя `orbitar-deploy` (без sudo и пароля — умеет
только принимать rsync в свой webroot), создаёт webroot, выпускает сертификат
Let's Encrypt и включает vhost. Повторный запуск безопасен.

Машина держит и другие сайты, поэтому скрипт ничего не переустанавливает и не
трогает чужие конфиги. Схема сертификата — как у соседей: аутентификатор
`webroot` через `/var/www/acme`, `installer` не используется, ssl-директивы
написаны в vhost руками. Продлевает `certbot.timer`, nginx после продления
перезагружает общий хук `/etc/letsencrypt/renewal-hooks/deploy/reload-nginx.sh`.

Сертификат выпускается **до** установки vhost: его 443-блок ссылается на файлы
сертификата, и без них nginx не загрузится. http-01 challenge в этот момент
отдаёт `acme-bootstrap` — он `default_server` и ловит ещё не настроенное имя.

### Автодеплой

`.github/workflows/deploy.yml` на каждый push в `main` синхронизирует репозиторий
в webroot по rsync (`--delete`, так что удалённые из репозитория файлы исчезают и
с сервера) и проверяет, что сайт отвечает 200.

Секреты репозитория:

| Секрет                | Значение                                                |
|-----------------------|---------------------------------------------------------|
| `DEPLOY_HOST`         | IP сервера                                              |
| `DEPLOY_USER`         | `orbitar-deploy`                                        |
| `DEPLOY_SSH_KEY`      | приватный ключ, публичный лежит в его `authorized_keys` |
| `DEPLOY_KNOWN_HOSTS`  | вывод `ssh-keyscan <DEPLOY_HOST>`                       |

Ключ CI — отдельный от административного: он пускает только под `orbitar-deploy`.

Ручной прогон — вкладка Actions → Deploy → Run workflow.
