# ORBITAR — демо платформера в стиле 16-битных консолей

Sci-fi платформер на чистом HTML5 Canvas без зависимостей. Внутреннее разрешение
320×224 (как у SNES/Mega Drive) с целочисленным масштабированием, палитра из ~40 цветов,
все тайлы и спрайты генерируются кодом при загрузке — никаких внешних картинок.

Три уровня по 12 экранов, каждый со своим набором тайлов, фонов, врагов и боссом.
Звук тоже синтезируется на лету: PSG-блипы, FM-удары и четыре трекерные темы — ни одного
аудиофайла.

## Запуск

Открыть `index.html` в браузере (работает и с `file://`), либо:

```
python3 -m http.server 8000
# → http://localhost:8000
```

## Управление

| Клавиши                 | Действие                                     |
|-------------------------|----------------------------------------------|
| ← / → или A / D         | бег                                          |
| Z / Space / ↑ / W       | прыжок (чем дольше держать, тем выше)        |
| Z                       | переход на следующий уровень на экране CLEAR |
| R                       | рестарт уровня (на финале — всей миссии)     |
| C                       | вкл/выкл scanlines                           |
| M                       | вкл/выкл весь звук                           |
| B                       | вкл/выкл музыку                              |
| набрать `LVL1`…`LVL3`   | чит: в начало нужного уровня                 |
| набрать `BOSS1`…`BOSS3` | чит: к боссу нужного уровня                  |
| набрать `NEXT`          | чит: сразу на следующий уровень              |

## ORBITAL FOUNDRY

Холодная гамма: синий металл, циановый неон, маджента. 240×14 тайлов, 34 энергоячейки.

- **Платформы**: твёрдый грунт с автотайлингом, парящие антиграв-платформы, односторонние
  решётки, горизонтальная и вертикальная движущиеся платформы, пружина.
- **Опасности**: лазерные шипы, патрульные дроны (на них можно прыгнуть сверху), бездонные ямы.
- **Босс WARDEN** (3 деления): арена запирается энергобарьером. Босс парит и стреляет
  наводящимися снарядами, затем телеграфирует (жёлтые глаза) и бьёт об пол — от места удара
  расходятся ударные волны, которые надо перепрыгнуть. После удара люк на корпусе открыт:
  прыжок сверху на ядро снимает деление. Пока щит поднят (пунктирная рамка), касание смертельно.

## VERDANT REACTOR

Тот же язык («неон по тёмному металлу»), но гамма сдвинута: зелёный металл, фиолетовый
неон на кромках, лаймовая подсветка антиграва, янтарный расплав вместо бездонных ям,
бирюзовые споровые наросты. Фон — споровое небо с двойной луной, грибные башни реактора,
свисающие корни. 240×14 тайлов, 28 энергоячеек.

Новые механики:

- **Осыпающиеся плиты** — держат ~0.7 с под ногами (индикатор гаснет с циана в красный),
  затем рассыпаются и отрастают через 2.5 с.
- **Донные вентиляторы** — столб восходящего потока (до 8 тайлов), поднимает игрока
  к верхним маршрутам; внутри столба сохраняется полный контроль по горизонтали.
- **Лазерные затворы** — луч от излучателя вниз, цикл «выкл → жёлтое предупреждение → луч».
  Проходы открываются только в паузах.
- **Расплав** — озёра вместо ям: поверхность анимирована, касание смертельно.

Новые враги:

- **CRAWLER** — ползун, шагает по грунту, разворачивается у стен и обрывов, гибнет от прыжка сверху.
- **SENTRY** — стационарная турель: наводится на сторону игрока, 28 кадров телеграфа (жёлтый
  ствол), затем горизонтальный выстрел. Гибнет от прыжка сверху. При возрождении на чекпоинте
  таймеры турелей сбрасываются — игрок всегда получает полный телеграф.
- **WASP** — перекрашенный дрон-патрульный.

**Босс ROOTMIND** (4 деления) — корневая машина, дерётся по земле, а не в воздухе:

1. *Stalk* — идёт к игроку по полу и плюётся веером из трёх спор по навесной траектории.
2. *Tell* — дрожит, глаза желтеют: телеграф рывка (~0.9 с).
3. *Dash* — рывок через всю арену; надо перепрыгнуть или отсидеться на боковых решётках.
4. *Crash* — удар о стену раскрывает броню: ядро наверху уязвимо ~2.7 с, прыжок сверху снимает деление.
5. С третьего деления дополнительно капает расплавом с потолка и выпускает ползунов из углов.

Скорость, частота спор и длительность фаз растут с каждым попаданием.

## ASHEN CITADEL

Тот же язык («неон по тёмному металлу»), гамма сдвинута в третий раз: пепельно-лиловый
металл, золотой неон на кромках, азурная подсветка антиграва, аметистовые шпили,
разлом пустоты вместо ям и расплава. Фон — пепельное небо с золотым затмением,
шпили цитадели, готическая колоннада со знамёнами и жаровнями. 240×14 тайлов,
29 энергоячеек.

Новые механики:

- **Фазовые плиты** — две группы, «золото» (`=`) и «азур» (`+`), гаснут по очереди.
  Цикл 260 кадров: 90 кадров тверда одна группа, 40 — тверды обе (углы плиты желтеют,
  руна гаснет — это окно для перескока), 90 — тверда вторая, 40 — снова обе.
- **Конвейерные ленты** — твёрдый пол, тянущий игрока в сторону бегущих стрелок:
  по ходу ленты разгон заметно быстрее, против хода — вязко.
- **Прессы** — висят под перекрытием: покой → телеграф (дрожь и пунктирная отметка
  зоны удара) → удар вниз → пауза → медленный подъём. Соседние прессы бьют вразнобой.
- **Разлом пустоты** — озёра вместо ям и расплава: фиолетовая рябь с искрами в глубине,
  касание смертельно.

Новые враги:

- **LEAPER** — прыгун: сидит, приседает (глаза желтеют — телеграф ~0.5 с), прыгает по дуге
  в сторону игрока. Гибнет от прыжка сверху.
- **SEEKER** — искатель: парящий аметистовый глаз, медленно тянется к игроку, у стен
  останавливается, вдали от игрока возвращается на место. Гибнет от прыжка сверху.
- **SAW** — пила: катается по своей рельсе над полом, неуязвима — только уклоняться.

Вместе с ними на уровне работают механики предыдущего сектора — осыпающиеся плиты,
донные вентиляторы и лазерные затворы, а также ползуны и турели в пепельной раскраске.

**Босс SOVEREIGN** (5 делений) — корона-разлом: не машина с бронёй и ядром, как два
первых босса, а разомкнутое кольцо с осколком пустоты внутри. Топтать её нельзя —
обод смертелен всегда и висит вне досягаемости прыжка. Урон наносит её же оружие:

1. *Reign* — кольцо парит под потолком, ведёт игрока и роняет искры регалий по дуге.
   Вокруг кольца вращаются осколки короны — их ровно столько, сколько делений осталось.
2. *Throne* — корона уходит в случайную точку арены (не ближе 72 px от игрока) и встаёт;
   пока она не замерла, телеграф не отсчитывается. Зрачок белеет.
3. *Tether* — один осколок сходит с привязи: он отлетает в сторону от игрока, падает
   к полу и идёт на него по горизонтали на высоте колена (вверх тянется еле-еле —
   перепрыгнуть можно всегда, стоять на месте нельзя). От короны к нему тянется привязь.
4. *Резонансный столб* — под троном горит широкая золотая шахта с галочками вверх и
   площадкой на полу. **Сбить осколок прыжком сверху внутри столба** — он уходит обратно
   в корону и сбивает деление. Сбить мимо столба — уйдёт в потолок впустую.
5. *Curtain* — за промах и за просроченный осколок (он трещит искрами перед тем, как
   лопнуть фонтаном) корона метёт арену занавесом осколков пустоты. Метла стартует со
   стороны игрока и всегда медленнее бега: с яростью занавес не разгоняется, а густеет.
6. Со второго деления в привязь добавляются осколки с потолка, с третьего корона
   роняет их и в фазе царствования и зовёт искателей из углов арены.

## Общее

- **Сбор**: 91 энергоячейка на три уровня, порталы выхода, по двенадцать чекпоинтов на уровень.
- **Физика**: ускорение/трение, переменная высота прыжка, coyote time, jump buffer,
  перенос игрока движущейся платформой, сплющивание при приземлении, частицы.
- **Графика**: три слоя параллакса на уровень, анимированные тайлы, битмап-шрифт 3×5 для HUD.
- Побеждённый босс не воскресает при возрождении на чекпоинте.
- **Звук**: всё синтезируется Web Audio без семплов (см. ниже).

## Звук

Ни одного аудиофайла: `js/audio.js` собирает голоса прямо из осцилляторов, как это делали
16-битные консоли.

- **PSG-блипы** — `PeriodicWave` со скважностью 12,5 / 25 / 50 % (прыжок, ячейки, фанфары).
- **FM-удары** — модулятор в частоту несущей, как у YM2612: попадания по боссу, выстрелы,
  удар пресса.
- **Шум** — три буфера: белый, ступенчатый (ближе к регистру шума PSG) и «металлический»;
  через биквад-фильтр с разгоном частоты получаются взрывы, осыпи и шипение потока.
- **Эхо** — общий посыл с обратной связью в духе SPC700, на него уходят мелодичные звуки.
- **Панорама** — источник звука панорамируется по своему положению на экране.
- **Непрерывные источники** — поток вентилятора и привязь осколка SOVEREIGN звучат
  зацикленными голосами, пока активны, а не повторами эффекта.

Музыка — мини-трекер: такт пишется строкой из шестнадцати токенов по 1/16
(`a4` — нота, `-` — держать, `.` — пауза; у ударных `k` — бочка, `s` — малый,
`h`/`H` — хэт, `c` — крэш, `r` — райд, `x` — кросс-стик, `t`/`T` — томы). Четыре канала:
ритм-гитара (квинт-аккорды с глушением ладонью), бас, соло-гитара и живая установка.

Тема — не петля, а песня: такты собраны в секции (вступление, куплет, подход,
припев, передышка, соло, кода), а поле `order` выстраивает из них форму на 50–54 такта,
то есть на 70–95 секунд. Повторы не звучат одинаково: секция с полем `from` наследует
каналы соседней и переписывает только свою партию (`=` вместо такта берёт родительский),
поэтому второй припев идёт с другой мелодией и сбивкой, а соло — поверх того же рифа.
Секция с `feel: 'clean'` уводит гитару на чистый канал и даёт нотам звенеть — между
тяжёлыми секциями получается арпеджио на кросс-стике.

По теме на уровень плюс общая тема боссов, которая включается при пробуждении и уходит
после победы. Планировщик работает с упреждением 0,16 с и вызывается из игрового цикла.

Браузеры не дают запустить звук до действия пользователя — контекст создаётся по первому
нажатию клавиши, состояние переключателей хранится в `localStorage`. При уходе на другую
вкладку контекст засыпает.

## Файлы

- `index.html` — канвас и подсказка по управлению.
- `js/audio.js` — звуковой движок: синтез эффектов, эхо, мини-трекер и темы уровней.
- `js/assets.js` — палитра, темы (таблицы подмены цветов), генератор спрайтов из пиксель-карт,
  процедурные тайлы и фоны для всех трёх уровней.
- `js/level.js` — карта ORBITAL FOUNDRY и его метаданные.
- `js/level2.js` — карта VERDANT REACTOR и его метаданные.
- `js/level3.js` — карта ASHEN CITADEL и его метаданные.
- `js/game.js` — движок: ввод, коллизии, сущности, механики, камера, боссы, отрисовка, HUD.

Тема уровня задаётся одной таблицей подмены ключей палитры (`TH_REACTOR`, `TH_CITADEL`
в `assets.js`) — все тайлы, декор, порталы и враги перекрашиваются из тех же пиксель-карт.
Цвета общих эффектов (пыль от врагов и плит, поток вентилятора) уровень задаёт полем `fx`.

## Отладка

- `index.html#lv=3` — старт на третьем уровне.
- `index.html#lv=3&x=43&y=10` — старт игрока в указанном тайле (удобно смотреть части уровня).
- `index.html#lv=3&x=221&y=10` — старт прямо у арены босса.
- `window.__dbg()` в консоли — текущее состояние уровня, игрока, врагов и босса
  (в том числе стадии фазовых плит и прессов).
- Чит-коды: `LVL1`…`LVL3` (начало уровня), `BOSS1`…`BOSS3` (чекпоинт у арены босса),
  `NEXT` (следующий уровень).
- `SFX.play('bossHit')`, `SFX.music('boss')`, `SFX.loop('tether', true)` в консоли —
  проверить отдельный звук, тему или зацикленный голос.

## Деплой

Продакшн: **https://orbitar.duckdns.org** — vps2, nginx, статика в `/var/www/orbitar`.

### Первичная настройка сервера

Один раз, от root:

```
scp deploy/provision.sh deploy/nginx-orbitar.conf root@vps2:/tmp/
ssh root@vps2 'CI_DEPLOY_PUBKEY="ssh-ed25519 AAAA... github-actions-deploy@orbitar" bash /tmp/provision.sh'
```

Скрипт заводит системного пользователя `orbitar-deploy` (без sudo и пароля — умеет
только принимать rsync в свой webroot), создаёт webroot, выпускает сертификат
Let's Encrypt и включает vhost. Повторный запуск безопасен.

Машина держит и другие сайты, поэтому скрипт ничего не переустанавливает и не
трогает чужие конфиги. Схема сертификата — как у соседей: аутентификатор
`webroot` через `/var/www/acme`, `installer` не используется, ssl-директивы
написаны в vhost руками. Продлевает `certbot.timer`, nginx после продления
перезагружает общий хук `/etc/letsencrypt/renewal-hooks/deploy/reload-nginx.sh`.

Сертификат выпускается **до** установки vhost: его 443-блок ссылается на файлы
сертификата, и без них nginx не загрузится. http-01 challenge в этот момент
отдаёт `acme-bootstrap` — он `default_server` и ловит ещё не настроенное имя.

### Автодеплой

`.github/workflows/deploy.yml` на каждый push в `main` синхронизирует репозиторий
в webroot по rsync (`--delete`, так что удалённые из репозитория файлы исчезают и
с сервера) и проверяет, что сайт отвечает 200.

Секреты репозитория:

| Секрет                | Значение                                                |
|-----------------------|---------------------------------------------------------|
| `DEPLOY_HOST`         | IP сервера                                              |
| `DEPLOY_USER`         | `orbitar-deploy`                                        |
| `DEPLOY_SSH_KEY`      | приватный ключ, публичный лежит в его `authorized_keys` |
| `DEPLOY_KNOWN_HOSTS`  | вывод `ssh-keyscan <DEPLOY_HOST>`                       |

Ключ CI — отдельный от административного: он пускает только под `orbitar-deploy`.

Ручной прогон — вкладка Actions → Deploy → Run workflow.
